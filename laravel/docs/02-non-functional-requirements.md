# 02 — Kebutuhan Nonfungsional

Status **Implemented** berarti mekanisme ditemukan pada kode, bukan sertifikasi keamanan atau bukti hasil uji runtime. **Partially** berarti hanya sebagian sasaran didukung bukti. **Not verified** berarti belum ada hasil pengukuran atau bukti implementasi yang cukup. Sasaran numerik yang tidak berasal dari kode ditandai sebagai usulan, bukan kemampuan terjamin.

| ID | Category | Requirement | Evidence in code | Status |
|---|---|---|---|---|
| NFR-01 | Security — authentication | Akses operasional harus mensyaratkan autentikasi session dan akun aktif. | `routes/web.php`: `auth`, `account.active`; `EnsureActiveAccount` mengeluarkan akun nonaktif; guard `web` di `config/auth.php` | Implemented |
| NFR-02 | Security — password hashing | Password yang dibuat, diubah, dan direset harus disimpan sebagai hash, bukan plaintext database. | `Hash::make` di `MasterDataController`, `PasswordController`, `UmiSeeder`; `Auth::validate`; tidak mengandalkan cast `hashed` pada `User` | Implemented |
| NFR-03 | Security — CSRF | Request mutasi harus dilindungi middleware forgery default `web` dan token pada form. | `@csrf` pada form Blade; tidak ada pengecualian di `bootstrap/app.php`; Laravel 13 memeriksa origin dengan token fallback | Implemented |
| NFR-04 | Security — validation | Input harus divalidasi server-side menurut tipe, rentang, referensi, dan keunikan yang relevan. | `Request::validate`, `Validator::make`, `Rule::exists/unique/enum`; jumlah lead 0–9999, tanggal, konfirmasi password | Implemented |
| NFR-05 | Security — authorization | Modifikasi lead harus mengikuti pemilik/usia; master data, reset, dan audit harus dibatasi Supervisor. | `Gate::authorize`, `LeadPolicy`, `Lead::isEditableBy`, `ensureSupervisor`, `abort_unless`; scoped binding route lead | Implemented |
| NFR-06 | Security — session | Login/pergantian password harus mengganti session ID; logout harus menginvalidasi session dan token. | `AuthController`, `PasswordController`; tidak ada revokasi eksplisit seluruh session perangkat lain | Partially |
| NFR-07 | Security — brute force | Login dan reset Supervisor harus dibatasi 10 request per menit oleh middleware. | `throttle:10,1` pada `login.store` dan `password.resets.store`; bukan klaim penguncian permanen akun | Implemented |
| NFR-08 | Security — confidentiality | Password sementara tidak boleh masuk audit; penampilannya dibatasi flash session. | `AuditLog` menerima metadata tanpa password; banner sekali tampil; `AuditLogTest`, `MasterDataTest`, `PasswordFlowTest` | Implemented |
| NFR-09 | Security — transport | Usulan: seluruh traffic produksi menggunakan HTTPS dan secure cookie; pemindaian tidak menemukan cookie autentikasi melalui HTTP. | `SESSION_SECURE_COOKIE` dapat dikonfigurasi; HTTPS/HSTS deployment tidak diverifikasi | Not verified |
| NFR-10 | Security — output | Teks dinamis harus di-escape; ekspor teks tidak dieksekusi sebagai formula. | Blade `{{ }}`; `DashboardXlsxExport::stringCell/escapeXml` menggunakan `inlineStr` dan XML escaping | Implemented |
| NFR-11 | Security — lifecycle akun | Akun baru/reset harus mengganti password minimal 8 karakter sebelum melanjutkan. | `must_change_password`, `EnsurePasswordIsChanged`, validasi `PasswordController`; akun demo seeder merupakan pengecualian | Partially |
| NFR-12 | Usability | Form harus menampilkan error, status hasil operasi, konfirmasi penghapusan, duplikat, dan jumlah tinggi. | `leads/index.blade.php`, `layouts/app.blade.php`, `master-data.blade.php`; toast dan confirm native | Implemented |
| NFR-13 | Usability / accessibility | Usulan: seluruh tugas utama dapat diselesaikan dengan keyboard pada lebar 360, 768, dan 1366 px tanpa kontrol terpotong; evaluasi WCAG 2.2 AA pada halaman inti. | Label form, `aria-expanded`, sidebar responsif, table overflow, reduced-motion di `public/css/umi.css`; belum ada audit aksesibilitas | Partially |
| NFR-14 | Usability — acceptance | Usulan: median SUS minimal 68 dan minimal 90% tugas UAT selesai tanpa bantuan. | Tidak ada hasil SUS/UAT; instrumen kosong pada [12-uat-plan.md](12-uat-plan.md) | Not verified |
| NFR-15 | Performance — query | Daftar lead, rincian dashboard, dan audit harus dibatasi per halaman serta memuat relasi yang dipakai secara eager. | Lead/dashboard `simplePaginate(50)`; audit `paginate(30)`; `with(...)`; agregasi SQL; indeks migration. Master data menggunakan `get()` tanpa pagination | Implemented |
| NFR-16 | Performance — export | Ekspor harus membaca data bertahap dan membersihkan file sementara setelah digunakan. | `DashboardXlsxExport`: `lazy(500)`, stream worksheet, `try/finally`; `DashboardController@export`: stream download dan unlink | Implemented |
| NFR-17 | Performance — response | Usulan: p95 halaman inti ≤2 detik dan ekspor 10.000 baris ≤10 detik pada 20 pengguna serentak, dataset 100.000 lead, perangkat server dan jaringan yang disepakati. | Tidak ada benchmark/load test; batas dashboard 31 hari tidak membuktikan waktu respons | Not verified |
| NFR-18 | Compatibility | Usulan: login, input, dashboard, unduhan, dan navigasi lulus pada dua versi mayor terbaru Chrome, Edge, Firefox serta Chrome Android. | HTML/Blade, SVG, `requestSubmit()`; tidak ada matriks pengujian browser | Not verified |
| NFR-19 | Compatibility — runtime | Runtime harus memenuhi dependency PHP/Composer, koneksi MySQL, dan extension XLSX. | `composer.json`: PHP `^8.3`; `config/database.php`; `DashboardXlsxExport` memakai `ZipArchive`; versi operasional server belum dibakukan | Partially |
| NFR-20 | Maintainability | Struktur kode harus memisahkan route, controller, model, policy, view, dan ekspor. | Struktur `app`, `routes`, `resources`; enum `Role`, `Lead::STATUSES`; tanpa service/FormRequest domain terpisah | Implemented |
| NFR-21 | Maintainability — regression | Usulan: setiap FR memiliki skenario positif/negatif yang dieksekusi sebelum rilis, tanpa kegagalan blocker. | 21 method test; belum ada test CRUD lead khusus; [11-black-box-test-cases.md](11-black-box-test-cases.md) belum dieksekusi | Partially |
| NFR-22 | Data integrity — references | Lead harus mereferensikan user/sumber/kategori yang ada dan mencegah penghapusan parent yang masih dipakai. | Tiga FK `restrictOnDelete`; audit FK `nullOnDelete`; `sessions.user_id` dan polymorphic bukan FK | Implemented |
| NFR-23 | Data integrity — uniqueness | Kombinasi rekap aktif harus unik, termasuk saat terjadi race condition. | `leads_unique_active_entry`, generated `active_flag`; pengecekan awal serta catch `UniqueConstraintViolationException` | Implemented |
| NFR-24 | Reliability — atomicity | Perubahan lead/master/reset dan pencatatan audit terkait harus commit atau rollback bersama. | `DB::transaction` di controller terkait; perubahan password sendiri dan seeder tidak dibungkus transaksi audit | Implemented |
| NFR-25 | Reliability — recovery | Usulan: backup database harian, RPO ≤24 jam, RTO ≤4 jam; lakukan restore drill minimal tiap semester. | Tidak ditemukan prosedur backup/restore atau hasil drill di sumber yang diperiksa | Not verified |
| NFR-26 | Reliability — availability | Usulan: availability bulanan ≥99% dengan monitoring `/up` setiap menit dan pencatatan insiden. | Health route pada `bootstrap/app.php`; monitoring/SLA aktual tidak tersedia | Not verified |
| NFR-27 | Auditability | Jejak perubahan harus menyimpan pelaku, waktu, objek, aksi, serta detail yang relevan tanpa mengklaim snapshot lengkap. | `AuditLog`; lead hanya mencatat lima jumlah status; tidak ada audit login/logout/pergantian password sendiri atau kebijakan retensi | Partially |
| NFR-28 | Localization | Antarmuka operasional harus menggunakan Bahasa Indonesia secara konsisten. | Blade berbahasa Indonesia; `config/app.php` default locale English dan timezone UTC; beberapa tanggal memakai `locale('id')`, lainnya tidak | Partially |

## Validasi dan tindak lanjut

Tidak ada klaim lulus penetration test, benchmark, audit aksesibilitas, restore test, maupun compatibility test. Pengukuran harus mencatat perangkat, dataset, jumlah pengguna, jaringan, waktu, dan bukti hasilnya. Kebutuhan fungsional terkait: FR-01–FR-26; kasus uji perilaku: [11](11-black-box-test-cases.md).
